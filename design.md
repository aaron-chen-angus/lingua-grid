# Design — LINGUA//GRID

## 1. Architecture
Single `index.html` with inline modules. Optional `/audio/*.mp3` hint files. `phrases.json` content is inlined into the script as `PHRASES` at build-free authoring time (copy from `data/phrases.json`).

```
Game (state machine)
 ├─ UI          DOM overlays: screens, HUD, barrier card
 ├─ Renderer    Canvas 2D highway, cycle, barriers, particles
 ├─ Speech      SpeechRecognition wrapper → Promise<Result>
 ├─ Scorer      pure functions: normalize, graphemes, levenshtein, similarity
 ├─ Audio       hint playback (MP3 → speechSynthesis fallback), SFX synth, mic analyser
 ├─ Store       localStorage runs, CSV/JSON export, webhook queue
 └─ Config/Phrases/Flags
```

## 2. State machine
`BOOT → UNSUPPORTED | REGISTER → MIC_CHECK → COUNTDOWN → RIDING → BARRIER_RISE → AWAIT_SPEAK ⇄ LISTENING → (PASS → RIDING | FAIL → AWAIT_SPEAK) … → FINISH → RESULTS → LEADERBOARD`
Timer runs from first `BARRIER_RISE` to final `PASS`, including hint playback and listening.

## 5. Hint audio eligibility
On boot: `await voicesReady()` (poll `speechSynthesis.getVoices()` + `voiceschanged`, 2 s timeout). For each language: eligible if `CONFIG.useBundledAudio` and HEAD `audio/{phraseId}.mp3` succeeds for ≥1 phrase, OR a voice whose `lang` starts with the language's base code exists. Prefer voices with "Natural"/"Online"/"Google" in name. Filter phrase list to those with audio when using bundled audio.

Note: Chrome on Windows lacks voices for several pool languages; Edge's online "Natural" voices cover far more. Bundled MP3s (generated by `.github/workflows/tts.yml`) make hints browser-independent.

## 6. Scoring algorithm (pure, in Scorer)
```
normalize(text, lang):
  t = text.normalize('NFC').toLowerCase()
  if lang=='ar': remove [\u064B-\u065F\u0670\u0640]  (tashkeel, tatweel)
  if lang=='he': remove [\u0591-\u05C7]              (niqqud, cantillation)
  if lang in (fr,de,es,vi,ms,id,en): keep diacritics for vi; for others ALSO compute a diacritic-stripped variant (NFD, remove \p{M})
  remove \p{P} and \p{S}; collapse whitespace; trim
  if lang in (zh,th,my): remove all whitespace
  if lang=='zh': convert to toneless pinyin syllables via pinyin-pro (pinyin(t,{toneType:'none',type:'array'}).join(' '))
  return t

graphemes(s) = [...new Intl.Segmenter(undefined,{granularity:'grapheme'}).segment(s)].map(x=>x.segment)
sim(a,b) = 1 - levenshtein(graphemes(a),graphemes(b)) / max(len(a),len(b),1)

windowSim(heard, target):   // tolerates extra words ("uh, bonjour comment ça va")
  if len(heard) <= len(target): return sim(heard,target)
  return max over substrings of heard with length in [len(target)-2, len(target)+2] of sim(sub,target)

score(results, phrase, lang) =
  max over alternatives h in results (up to 5) and targets t in [phrase.text, ...phrase.accept]
      of windowSim(normalize(h), normalize(t))
```
Pass iff `score ≥ CONFIG.threshold[lang] ?? CONFIG.threshold.default`.
Rationale: speech-to-text similarity measures intelligibility (did the recogniser understand you), which is the same approach casual pronunciation games use. It is not phoneme-level assessment. Phase 2 option: Azure Pronunciation Assessment via a proxy for true accuracy/fluency scores.

## 7. Speech wrapper
```
listen(lang) → Promise<{alternatives:[{transcript,confidence}], error?}>
 - new webkitSpeechRecognition(); lang, interimResults=true, maxAlternatives=5, continuous=false
 - onresult: emit interim to UI; on isFinal resolve
 - hard stop at CONFIG.maxListenMs → recognition.stop()
 - errors: no-speech → resolve empty (counts as attempt, message "Didn't catch that"),
   not-allowed → MIC_CHECK screen, network → offline banner,
   language-not-supported → swap language (R3.5)
```
Mic analyser (getUserMedia) runs continuously for the waveform; SpeechRecognition runs independently.

## 8. Data model
```js
Run = {
  id, createdAt, player:{name, age, gender},
  finalTimeMs, elapsedMs, penaltyMs, bonusMs, hints, skips, perfects, maxCombo,
  languages: ['en','th',...],               // order played
  swaps: [{from,to,reason}],
  stages: [{ index, lang, phraseId, target, heard, similarity, threshold,
             attempts, hints, passed, skipped, perfect, stageMs,
             attemptLog:[{heard, similarity, t}] }],
  userAgent
}
```
localStorage: `{ runs: Run[], pendingWebhook: Run[] }`. CSV export: one row per stage with player columns repeated.

## 9. Visual design
- Palette: bg `#02040A`, grid cyan `#00E5FF`, deep blue `#0066FF`, orange `#FF7A00`, hot orange `#FFB347`, text `#E6FBFF`.
- Player = cyan; barriers = orange; pass = cyan flash; fail = orange/red shake.
- Fonts: Orbitron 500/700/900 (UI, HUD, numbers); Noto Sans + script-specific Noto for phrases; IPA in Noto Sans (IPA-safe) italic, cyan.
- Renderer: horizon at 40% height; road trapezoid with scrolling horizontal lines (speed-driven) and converging vertical lanes; glow via `ctx.shadowBlur` + `globalCompositeOperation='lighter'`; distant wireframe skyline parallax; light-cycle drawn as vector silhouette with rear light trail ribbon; particles for shatter; subtle CRT scanline overlay (CSS).
- Barrier card: DOM overlay (crisp text) anchored above canvas barrier, glassmorphism panel with orange neon border, rises with clip-path scan animation.
- HUD: top-left STAGE 03/10 + language chips; top-center timer mm:ss.cs; top-right PENALTY +10s and COMBO x3; bottom-center SPEAK (SPACE) and HINT (H, −5s) buttons; SYNC meter ring around SPEAK button.
- Speed: cruising while barrier awaits (cycle slows to near stop in front of barrier), boost after pass.

## 10. Error handling summary
| Case | Behaviour |
|---|---|
| Unsupported browser | Dedicated screen |
| Mic denied | Instructions + retry |
| Offline / network | Banner, pause timer? No — timer continues; allow retry |
| No speech | "Didn't catch that", attempt counted |
| Language unsupported | Silent swap, logged |
| Hint audio fails | Try speechSynthesis; if none, no penalty and toast |
| Webhook fails | Queue, retry next load |

## 11. Testing
- `tests.html`: loads the Scorer module (duplicated via `<script>` block copy or shared `scorer.js` — allowed as a static file) and asserts cases: exact match = 1; punctuation/case ignored; Arabic with/without tashkeel ≈ 1; Mandarin homophones (他/她) pass; extra filler words still pass; wrong phrase < 0.4.
- Manual checklist: each language once in Chrome and Edge on Windows; mic denied path; offline path.
